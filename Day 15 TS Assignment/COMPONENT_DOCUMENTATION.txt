METHODS/FUNCTIONALITY:
---------------------
- No TypeScript methods (static component)
- Uses hover effects for link interaction
- Image tag for logo integration

ICONS USED:
-----------
- heroMagnifyingGlass: Search icon from ng-icons library

================================================================================
                   4. INSURANCE-PROFILES COMPONENT (MAIN)
================================================================================

LOCATION: src/components/insurance-profiles/

COMPONENT STRUCTURE:
-------------------
- Type: Standalone Angular Component
- Selector: 'app-insurance-profiles'
- Imports: NgIconComponent (for card icons)
- Purpose: Interactive insurance type selection with quote form

TYPESCRIPT CLASS PROPERTIES:
----------------------------
1. activeCard: string = 'auto'
   - Tracks which insurance card is currently selected
   - Default value: 'auto'

TYPESCRIPT METHODS:
------------------
1. selectCard(card: string)
   - Parameter: card (string) - name of selected card
   - Updates activeCard property
   - Triggers visual state change in UI

STYLING APPROACH:
-----------------
Layout Method: FLEXBOX WITH NESTED CONTAINERS

Main Container:
  - .profiles-container: Flex column layout
  - flex-direction: column (stacks elements vertically)
  - align-items: center (centers horizontally)

Card Grid:
  - .cards-row: Flex row layout
  - display: flex
  - justify-content: center (centers cards)
  - gap: 15px (spacing between cards)
  - flex-wrap: wrap (responsive wrapping)

Individual Cards:
  - .card: Flexbox with column direction
  - width: 140px, height: 120px (fixed dimensions)
  - border: 1px solid #ddd (default border)
  - border-radius: 8px (rounded corners)
  - cursor: pointer (shows clickable)
  - position: relative (for absolute children)
  - transition: all 0.2s ease (smooth state changes)

Key CSS Terms Used:
  - .card.active: Selected card state (2px solid primary-color border)
  - .card-content: Inner flex container for icon + label
  - .card-icon: Icon styling
  - .card-label: Text below icon
  - .icon-group: Container for multiple icons (bundle card)
  - .bundle-badge: Absolute positioned "Bundle & Save" badge
  - .radio-circle: Unselected state indicator (empty circle)
  - .check-mark: Selected state indicator (filled circle with checkmark)
  - .quote-section: Bottom section with form
  - .quote-input-group: Flex container for input + button

Position Properties:
  - position: relative (on .card for child positioning)
  - position: absolute (on .bundle-badge and .check-mark)
  - top: -8px (badge above card)
  - bottom: -10px (checkmark below card)

ANGULAR FEATURES USED:
----------------------
1. Property Binding:
   - [class.active]="activeCard === 'auto'"
   - Conditionally adds 'active' class when condition is true

2. Event Binding:
   - (click)="selectCard('auto')"
   - Calls selectCard method when card is clicked

3. Angular Control Flow (@if/@else):
   - @if (activeCard === 'auto') { ... }
   - @else { ... }
   - Shows check-mark or radio-circle based on selection state

ICONS USED:
-----------
- heroTruck: Auto insurance icon
- heroHome: Home insurance icon
- heroBriefcase: Business insurance icon
- heroCheck: Checkmark in selected state
- Icon sizes: 2rem (single icons), 1.5rem (bundle icons), 0.8rem (checkmark)

FORM ELEMENTS:
--------------
- .zip-input: Text input for zip code
  - border-radius: 4px 0 0 4px (rounded left corners only)
  - width: 150px
- .start-btn: Submit button
  - background-color: var(--primary-color) (maroon)
  - border-radius: 0 4px 4px 0 (rounded right corners only)
  - Creates seamless input-button combination

INTERACTIVE STATES:
-------------------
- Hover: box-shadow: 0 4px 8px rgba(0,0,0,0.1) (shadow on hover)
- Active: 2px solid border with primary color
- Button hover: Darker maroon (#5a0000)

================================================================================
                        COMMON STYLING PATTERNS
================================================================================

CSS VARIABLES USED:
-------------------
- var(--primary-color): Maroon color (#800000 or similar)
- var(--text-color): Default text color (likely #333 or #444)

COMMON CSS TECHNIQUES:
----------------------

1. FLEXBOX USAGE (Most Common):
   - display: flex
   - justify-content: (space-between, center, flex-start)
   - align-items: (center, flex-start, stretch)
   - flex-direction: (row, column)
   - gap: (for spacing between flex items)

2. POSITIONING:
   - position: relative (parent containers)
   - position: absolute (child elements like badges)
   - z-index (layering elements)

3. TRANSITIONS:
   - transition: all 0.2s ease (smooth animations)
   - Used on cards for hover effects

4. BORDER-RADIUS:
   - 8px (cards)
   - 4px (buttons, inputs)
   - 50% (circular elements like checkmarks)
   - Partial radius: 4px 0 0 4px (left side only)

5. BOX-SHADOW:
   - 0 4px 8px rgba(0,0,0,0.1) (subtle shadow on hover)

6. HOVER EFFECTS:
   - :hover pseudo-class
   - Changes: background-color, text-decoration, box-shadow


================================================================================
                        ANGULAR PATTERNS USED
================================================================================

1. STANDALONE COMPONENTS:
   - All components use standalone: true
   - No NgModule needed
   - Direct imports in component decorator

2. COMPONENT DECORATOR PROPERTIES:
   - selector: Custom HTML tag name
   - standalone: true (modern Angular pattern)
   - imports: Array of dependencies
   - templateUrl: External HTML file
   - styleUrl: External CSS file

3. DATA BINDING:
   - Property Binding: [class.active]="condition"
   - Event Binding: (click)="method()"
   - Interpolation: {{ property }} (not used much in these components)

4. CONTROL FLOW:
   - @if/@else (Angular 17+ syntax)
   - Replaces *ngIf structural directive

5. ICON LIBRARY:
   - @ng-icons/core package
   - NgIconComponent imported where needed
   - Heroicons icon set used (hero prefix)


================================================================================
                         RESPONSIVE DESIGN
================================================================================

TECHNIQUES USED:
----------------
1. flex-wrap: wrap (allows items to wrap on smaller screens)
2. max-width properties (limits container size)
3. min-width on columns (prevents too-narrow columns)
4. percentage-based padding (relative spacing)
5. Gap property (spacing that adjusts with layout)
